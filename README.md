# RailTheme for Blender

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
![Blender 2.8+](https://img.shields.io/badge/Blender-2.8%2B-orange)

**RailTheme** is a dark, industrial-inspired UI theme for Blender that brings the gritty, utilitarian feel of late‑90s sci‑fi and heavy machinery into your 3D workspace.  
It takes visual cues from the golden era of PC gaming—think amber displays, warning stripes, and weathered metal—but stays original and tailored for modern Blender workflows.

![RailTheme Preview](./Assets/RailTheme.jpg)

## ✨ Features

- **High‑contrast dark background** – reduces eye strain during long modeling sessions.
- **Amber/orange accent palette** – highlights active elements, buttons, and selection states.
- **Muted grey & steel tones** – keep the interface clean and focused on your art.
- **Terminal‑inspired text colours** – subtle green/cyan hints for improved readability.
- **Optimised for all editors** – carefully adjusted colours for the 3D viewport, Node Editor, UV Editor, and more.
- **Consistent theming** – modifiers, properties, and outliner all follow the same industrial logic.

## 📦 Installation

1. Download the `RailTheme.xml` file from this repository.
2. Open Blender and go to **Edit** > **Preferences** > **Themes**.
3. Click the **Install…** button at the bottom of the panel.
4. Select the downloaded `RailTheme.xml` file.
5. From the theme preset dropdown, choose **RailTheme**.
6. (Optional) Tweak any colours and save your own preset.

> **Note:** The theme works with Blender 2.80 and above, including 3.x and 4.x releases.

## 🎨 Customization

You can modify the theme by editing the XML file directly. All colour values are stored in hexadecimal (`#RRGGBB`) format.  
Common adjustments include:

- Increasing the overall brightness by raising the background values.
- Changing the accent colour to your preferred hue (e.g., blue or green).
- Tuning the contrast of text and panel borders.

If you create an interesting variant, feel free to share it via a pull request!
